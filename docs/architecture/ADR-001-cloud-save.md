# ADR-001：正式发布版玩家数据云端持久化

- 状态：已确认，2026-10-28，项目负责人明确要求。
- 优先级：覆盖 V1.0 文档中“本地存档”“云存档可选”的旧决策。

正式发布版玩家持久化数据必须存储在云端或服务端，不允许存储在用户设备本地。范围包括关卡进度、清理和剧情进度、奖励、道具及玩家设置。禁止使用 localStorage、IndexedDB、文件或微信／抖音本地存储 API 保存这些数据，也不得在云端失败时静默回退本地。

运行中的棋盘、输入、动画及未提交状态允许保存在内存中；退出后不提供本地恢复。随包发布的关卡、配置、图片和音频不是玩家存档。本 ADR 不禁止引擎和平台正常的静态资源缓存。

Domain / Mode 通过 ISaveService 访问存档，不接触云 SDK。后续选择平台云能力或轻量服务端，不为本决策立即建设大型独立后端。开发和单测只使用内存测试替身，不建立生产本地存档实现。

云端存档是正式上线的前置条件，不是可选增强。上线前必须确定用户身份映射、访问控制、存档版本迁移、并发冲突与重试策略。云端读失败不能当作新玩家空存档；写失败不能显示已保存或静默丢失进度。后续实现时明确待确认状态和重试体验，避免重复发奖。通用“云失败降级”不得绕过本决策。

上线验收：确认正式构建没有玩家数据本地写入路径；验证换设备恢复、读写失败、重试、版本迁移以及跨用户隔离。当前初始化不提供云服务或生产存档能力。
